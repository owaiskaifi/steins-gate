🔮 Steins Gate

Array Trend Predictor API

Analyze numerical arrays and predict their trend patterns using machine learning.

🎯 Prediction Types
NO_COUNT INCREASE DECREASE STABLE VARIANCE
📡 API Endpoint
POST /predict
Content-Type: application/json

{
  "arr": [1.0, 2.5, 1.8, 3.2, 2.1]
}
📝 Example Response
{
  "STATUS": "INCREASE"
}
